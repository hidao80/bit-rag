bit-rag

The simplest local RAG API server. FastAPI + LangChain + ChromaDB + Ollama — no separate database or web server to stand up.

View on GitHub Quick Start

Why bit-rag

Spinning up a full database server or web framework just to try RAG is overkill. bit-rag exposes retrieval-augmented generation as a small, self-contained Web API — so it drops straight into existing apps and webhooks, and runs entirely on your own machine.

Features

🐳

One-command start

docker compose up boots Ollama and the app together. Models are pulled automatically on first run.

🔒

Fully self-hosted

No cloud API keys, no external vector database. Everything runs locally with Ollama and ChromaDB.

📄

Markdown-aware ingest

Splits by heading, keeps tables intact as structured JSON rows, and merges short fragments for better retrieval.

🌐

Multilingual answers

Set a response locale per request — answer the same question in English, Japanese, or any language your model supports.

Quick Start

Run with Docker (recommended)

docker compose up

Run locally

ollama pull nomic-embed-text:latest
ollama pull qwen2.5:1.5b
uv sync
uv run uvicorn src.main:app --reload

API at a glance

curl -X POST "http://localhost:8000/query" \
  -H "Content-Type: application/json" \
  -d '{"question": "What is LangChain?"}'
